<Thesis>

- 이 사이트는 AI가 만든 설명을 글·이미지·다이어그램·상호작용으로 읽고, 피드백하며 발전시키는 지식베이스다.
- 사람은 배우려는 질문과 이해되지 않는 지점을 말하고, AI는 자료 확인·작성·구현·검증을 맡는다.
- 완성된 문서는 웹에서 검색하고 페이지나 절의 링크로 공유한다.

</Thesis>

AI와 나눈 대화에는 좋은 설명이 많지만, 시간이 지나면 다시 찾거나 다른 사람에게 보여 주기 어렵다.
텍스트를 Markdown 파일로 모아 두는 것만으로도 관계와 흐름이 쉽게 눈에 들어오지는 않는다.
이 사이트는 그 설명을 **다시 읽고, 그림으로 이해하고, 직접 단계를 따라갈 수 있는 웹 문서**로 축적한다.

이 덱은 Starlight로 그 일을 하는 방법을 다룬다. Astro나 MDX를 공부하거나 문서 파일을 직접 쓸 필요는 없다.
어떤 결과를 AI에게 요청하고, 완성된 화면에서 무엇을 보고 피드백할지 익히면 된다.
